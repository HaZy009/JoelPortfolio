Elite Vet Clinic Website

Elite Vet Clinic is a complete veterinary clinic website designed and developed as part of a user interface design project.

The website includes:

  • Multi-page navigation with React Router
  • Veterinary services presentation
  • Appointment booking workflow
  • Interactive scheduling calendar
  • Appointment confirmation process
  • Responsive design for desktop and mobile devices

This project demonstrates front-end development, routing, responsive design, user interface principles and form validation using React and Vite.

SimonPulse

SimonPulse is an interactive memory game inspired by Simon Says. The user must memorize and repeat increasingly longer sequences of lights and sounds.

The game includes:

  • Interactive Simon board with visual feedback
  • Difficulty settings that change the sequence speed
  • Sound effects with an ON/OFF setting
  • Current score and best score tracking
  • Best score saved with local storage
  • Responsive design for desktop and mobile devices

This project demonstrates React state management, user interaction, responsive layout design, audio feedback, and high-fidelity prototyping.

Live Demo GitHub

KeyVerse

KeyVerse is a high-fidelity e-commerce prototype specializing in digital video game keys for PC and consoles. The website was designed to provide a fast, intuitive, and engaging shopping experience inspired by modern gaming marketplaces.

The website includes:

  • Multi-page navigation with React Router
  • Fully functional faceted search
  • Platform-specific product catalogs
  • Interactive shopping cart with LocalStorage
  • Three-step checkout process with a progress stepper
  • Order confirmation and post-purchase satisfaction survey
  • Responsive design for desktop, tablet and mobile devices

This project demonstrates user-centered interface design, faceted search, React state management, responsive layouts, shopping cart persistence, and high-fidelity e-commerce prototyping.

Live Demo GitHub
