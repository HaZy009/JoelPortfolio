Elite Vet Clinic Website

Elite Vet Clinic is a complete veterinary clinic website designed and developed as part of a user interface design project.

The website includes:

  • Multi-page navigation with React Router
  • Veterinary services presentation
  • Appointment booking workflow
  • Interactive scheduling calendar
  • Appointment confirmation process
  • Responsive design for desktop and mobile devices

This project demonstrates front-end development, routing, responsive design, user interface principles and form validation using React and Vite.
